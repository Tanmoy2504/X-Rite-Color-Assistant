# X-Rite Color Assistant for Lenovo Laptops

The **X-Rite Color Assistant** is a display calibration utility developed by **Lenovo Inc.** in collaboration with **X-Rite**.  
It is designed for select **ThinkPad** and **Legion** laptops equipped with 100% sRGB or DCI-P3 panels and factory calibration.

---

## Product Description
X-Rite Color Assistant enables Lenovo laptop users to restore and manage factory-calibrated ICC color profiles.  
This ensures accurate color reproduction across supported displays, maintaining the quality intended by Lenovo and X-Rite.

Key capabilities include:
- Restoring factory ICC profiles (sRGB, HDR, Rec.709, etc.).
- Managing display calibration settings after a clean OS installation or system reset.
- Providing access to a utility that may not always appear on Lenovo’s official support pages.

---

## Scope of Support
- Supported only on **Lenovo ThinkPad** and **Legion** models with factory-calibrated 100% sRGB / DCI-P3 displays.  
- Other vendors (Dell, Asus, Acer, HP, etc.) are **not supported**.  
- Tested successfully on **Legion 5 Pro (16ARH7H)**.  
- Compatibility may vary depending on your Lenovo model.

---

## Installation
1. Download the installer from the **Releases** section of this repository.  
2. Run the installer with **Administrator privileges**.  
3. Open the application and navigate to **Settings**.  
4. Select **Restore Profile** to apply factory ICC profiles.  

**Requirements:**
- Administrator access is necessary to download and install ICC profiles into the system directory.  
- The installer is digitally signed by **X-Rite Incorporated** and should not be flagged by antivirus software.  
- Microsoft Edge SmartScreen may prompt during download; select **Keep File** to proceed.
